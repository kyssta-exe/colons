# About Dots

## Overview

Dots are remarkably capable, always-on AI agents built to handle everything - powered by GPT-6 Astra. They represent a fundamentally new way to interact with AI: persistent, proactive assistants that work continuously on your behalf.

**Launch Date:** September 29, 2026
**Developer:** OpenAI
**Base Model:** GPT-6 Astra (OpenAI's most aligned model)
**Availability:** Rolling out to Pro, Business Premium, and Enterprise plans in eligible markets

---

## Core Architecture

### Foundation Model
- **GPT-6 Astra**: Advanced reasoning model optimized for agentic workflows
- **Frontier Intelligence**: Capable of complex, multi-step autonomous operation
- **Learning Capabilities**: Improves through feedback over time

### Cloud Infrastructure
- **Dedicated Cloud Computer**: Each dot operates on isolated cloud hardware
- **24/7 Operation**: Continuous availability for tasks and background work
- **Resource Isolation**: Separate from user's local machine unless explicitly connected
- **Scalable Compute**: Can be scaled for increased speed or workload capacity

### Memory System
- **Cross-Conversation Context**: Remembers context between conversations
- **Feedback Integration**: Learns from user feedback and corrections
- **Connected App Data**: Forms memories from connected applications
- **ChatGPT Memory Sync**: Inherits context from existing ChatGPT memory

## Working Mechanisms

### 1. Task Assignment Process

#### Initial Setup
1. Create dot in ChatGPT desktop app or web
2. Name your dot (default: @yourname-dot)
3. Customize avatar and pet
4. Connect desired applications
5. Define goals and responsibilities

#### Task Execution Flow
1. **Goal Definition**: User describes what they want accomplished
2. **Context Gathering**: Dot gathers relevant information from connected apps
3. **Plan Creation**: Breaks down into actionable steps
4. **Autonomous Execution**: Works through steps with minimal intervention
5. **Review & Feedback**: Presents results for user review
6. **Iteration**: Incorporates feedback and continues improvement

### 2. Memory & Learning System

- **ChatGPT Memory**: Inherits existing context and preferences

## Safety & Privacy Features

### 1. Built-in Safeguards

#### Isolation Security
- **Cloud Computer Separation**: Works on isolated cloud machine
- **Password Protection**: Uses saved passwords without model exposure
- **Read-Only Proactive Research**: Cannot send messages or modify data
- **Local Computer Separation**: Optional and separately controlled

#### Behavior Monitoring
- **Malicious Instruction Defense**: Detects and defends against harmful prompts
- **Harm Behavior Monitoring**: Watches for potentially dangerous activities
- **Auto-Pause on Safety Concerns**: System can stop operations when needed
- **Security Logging**: All actions tracked for audit purposes

### 2. Access & Permissions Control

#### App Permissions
- **User-Controlled Access**: Only connected apps can be accessed
- **Granular Management**: Per-app permission settings
- **Real-Time Updates**: Permissions changeable at any time
- **Disconnect Capability**: Remove access without data deletion

#### Custom Rules Engine
- **Action Classification**: Define behaviors for specific action types
- **Four Rule Types**:
  1. **Take Action Without Asking**: Fully autonomous execution
  2. **Take Action If Pre-Approved**: Execute when explicitly requested
  3. **Ask Before Taking Action**: Require confirmation before proceeding
  4. **Hand Off to You**: Transfer task back to human user

#### Approval Workflows
- **Auto-Review Checks**: All actions evaluated against rules
- **Sensitive Task Protection**: Critical actions always require user action
- **Password Changes**: Always handled by user personally
- **Purchase Approvals**: Configurable spending limits and oversight

### 3. Data Privacy

#### Data Usage Policies
- **Workspace Data**: Not used to improve models by default (Business/Enterprise/Edu)
- **Personal Plans**: User-controllable data usage settings
- **Proactive Research**: Not directly trained on
- **Dot Notes**: Not used for model training
- **Conversation Usage**: Only counted toward limits when using Codex/ChatGPT Work

#### Data Deletion
- **Dot Reset**: Complete deletion of conversations, memories, and tasks
- **Memory Purging**: Remove specific memories or complete history
- **App Disconnection**: Clean removal of application access
- **Scheduled Task Cleanup**: Remove recurring task definitions

- **Creation Only Desktop**: Cannot create new dots on mobile devices

- **US Only**: Currently limited to US customers

### 3. Functional Constraints

#### Email Integration
- **No Standalone Addresses**: Dots cannot have independent email addresses
- **Personal Account Only**: Limited to user's existing email accounts

#### Voice Communication
- **No Outbound Calls**: Cannot initiate voice calls to users
- **Incoming Only**: Users must call dots for voice interaction

#### Data Usage
- **Training Restrictions**: Certain data cannot be used for model improvement
- **Usage Limits**: Conversation limits for specific task types
